# BiliBlockFusion

B 站内容过滤油猴脚本，基于 [BiBiBSPUserVideoMonkeyScript](https://github.com/hgztask/BiBiBSPUserVideoMonkeyScript) 二次开发。

## 安装

安装 Tampermonkey 或脚本猫，导入 `dist/BiliBlockFusion.user.js`。按 `` ` `` 键打开主面板。

## 更新

**v2.0.0**

相对 v1.2.0 是面板与配置方式的重构；规则键与配置存储格式沿用 1.2，升级后无需重新配置。

- **面板**：顶层页签收敛为 5 个（规则 / 页面 / AI 规则 / 高级 / 诊断与关于），
  低频项移入「高级」；页面与高级面板统一为「设置行 + 分组」，说明收进 ⓘ 气泡；
  规则信息按实体归组、默认只列出有内容的规则；油猴菜单收敛为单一「主面板」入口
- **AI 规则（新增）**：写一句需求 → 生成完整 Prompt → 交给任意 AI →
  粘回 JSON → 校验并预览差异 → 一键应用，支持撤销
- **规则真正生效**：1.2 中相当一部分规则配置了也不命中——uid 范围与时间范围判定写反、
  模糊匹配遇大写失效、正则规则遇空格失效、组合规则的标题/简介条件被无关的 tag 校验覆盖、
  话题 tag 规则没有调用点、直播间 id 类型不一致、合作视频成员检查传错参数；
  首页卡片还把播放量当成弹幕数，Bewly 首页与分区页的弹幕数、时长也解析错，
  相关指标规则同样失效
- **规则编辑**：规则内容抽屉可直接编辑并保存回写，取代原来的逐条删除 +「清空项 / 全部移除」
- **主题**：恢复亮色 / 自动 / 暗色三档，不再只能跟随 B 站
- **性能**：诊断页首次打开的主线程长任务 1147ms → 0；首页轮询反复抛出的类型错误已消除
- **稳定性**：等级限制改不了数值并反复弹窗、直播分区白名单删不掉、
  两个页面元素开关未接线、替换处理总开关不保存、面板关闭再打开后屏蔽日志停更
- **其他**：删除不参与屏蔽的「弹幕词管理」页与「颜色设置」卡；关于页分别列出本仓库与原作者的入口

**v1.2.0**

- 适配新版 BewlyCat 卡片结构，修复屏蔽失效
- 屏蔽方式改为三态：移除 / 叠加层 / 隐藏
- 修复移除卡片后留下的空白，后续卡片能顶上来
- 补齐 BV 去重与增量扫描，降低轮询开销
- 面板改用 Fluent 2 设计令牌
- 修复面板无法滚动、抽屉开合抽搐

**v1.1.0**

- 修复性能问题
- 改进 BewlyBewly 下隐藏模式的空白
